kEmacs で文字コード・改行コードを変更するキー操作は以下の通りです。

1. 文字コード・改行コードの変更 — set コマンド

^X A（Ctrl+X 押下 → A）

このコマンドを実行すると、「Variable to set:」 とプロンプトが出るので、以下の環境変数名を入力します。

| 変数   | 対象                       | 説明                           |
|--------|----------------------------|--------------------------------|
| $fcode | グローバル（新規バッファ） | デフォルトのファイル文字コード |
| $tcode | 端末全体                   | 端末表示用文字コード           |
| $bcode | 現在のバッファのみ         | ファイル入出力時の文字コード   |

値を入力する際は、文字コード名の後ろに / と改行コードを指定できます。

文字コードの指定方法


JIS-NEW-ASCII   （JIS 新字でアルファベット）
JIS-OLD-ROMAJI  （JIS 旧字でローマ字）
SJIS            （シフト JIS）
UJIS            （EUC-JP / ユニバーサル JIS）
UTF8            （UTF-8）


改行コードの指定方法


LF/    → LF のみ（Unix スタイル）
CR/    → CR のみ（Mac スタイル）
CRLF/  → CR + LF（Windows/DOS スタイル）


使用例:


^X A    →  「Variable to set: 」  →  $bcode  →  「Value: 」  →  UTF8/CRLF/


これにより、現在のバッファの文字コードを UTF-8、改行コードを CRLF に設定できます。



2. BINARY モードのトグル — コード変換オン/オフ

^X M : BINARY モードを追加（コード変換を停止）
^X ^M : BINARY モードを削除（コード変換を有効化）

BINARY モードでは、バッファのすべてのバイトがそのまま通過します（KS_BINARY）。このモードを解除すると、$bcode で指定されたコード体系によって JIS/UJIS/SJIS 間の変換が行われます（KS_KANJI）。



3. コマンドライン起動時の指定

kEmacs を起動する際にコマンドラインオプションでも指定可能です。

sh
kemacs -f UTF8/CRLF/  file.txt    # ファイルコード = UTF-8, 改行 = CRLF
kemacs -t UJIS/       file.txt    # 端末コード = UJIS, 改行 = LF (デフォルト)
kemacs -f SJIS/       file.txt    # ファイルコード = SJIS
kemacs -b                         # BINARY モードで起動


コード体系のオプション:
- j / J : JIS
- e / u : UJIS
- s : SJIS
- w : UTF-8

改行コードのオプション:
- l : LF
- c : CR
- d : CRLF (DOS)



4. 現在の設定確認

^X = （Ctrl+X → =）

これにより、カーソル位置、文字コード等が含むステータスラインが表示され、現在のコード体系を確認できます。また、モードラインの %c フィールドに現在のコード体系が表示されます。
